# TikTok shop: playbook and store site

A small online shop selling to US shoppers through TikTok, run from China.

- [`playbook/`](playbook/README.md) has the guides: product research, cost model, store and website,
  TikTok channels and ads, sourcing and fulfillment, legal/tax/payments, and the launch plan.
- The new brand's product pages will go here once the brand name, samples and prices are settled.
- `.claude/skills/llm-council/` is the LLM Council skill for Claude Code. Say "council this" to
  pressure-test a decision.

The site is plain HTML, CSS and JavaScript, published with GitHub Pages from `main`
(`.nojekyll` keeps GitHub from processing it).
